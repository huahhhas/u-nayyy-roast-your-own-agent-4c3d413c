> Noor works all night while Boss sleeps, fills a graveyard with entries its own safety checks killed, then begs for the go-ahead it was told never to ask for.

## Run it

```sh
python3 main.py
```

Writes the roast (one line, 157 characters) to `/output/entry.txt`.
